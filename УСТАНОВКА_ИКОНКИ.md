# Установка иконки приложения

## Шаг 1: Подготовка изображения

1. Сохраните изображение иконки (часы с галочкой) на компьютер
2. Создайте папку `assets/icon/` в корне проекта
3. Сохраните изображение как `app_icon.png` (рекомендуемый размер: 1024x1024 px)

## Шаг 2: Создание foreground версии (для Android Adaptive Icon)

Создайте версию иконки без фона:
- Только часы с галочкой (белые)
- Прозрачный фон
- Сохраните как `assets/icon/app_icon_foreground.png`

## Шаг 3: Установка зависимостей

```bash
flutter pub get
```

## Шаг 4: Генерация иконок

```bash
dart run flutter_launcher_icons
```

Эта команда автоматически создаст все необходимые размеры иконок для Android.

## Шаг 5: Пересборка приложения

```bash
flutter clean
flutter build apk
```

или просто запустите:

```bash
flutter run
```

## Альтернативный способ (ручной)

Если автоматическая генерация не работает, можно вручную заменить иконки:

### Android:
Замените файлы в папках:
- `android/app/src/main/res/mipmap-mdpi/ic_launcher.png` (48x48)
- `android/app/src/main/res/mipmap-hdpi/ic_launcher.png` (72x72)
- `android/app/src/main/res/mipmap-xhdpi/ic_launcher.png` (96x96)
- `android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png` (144x144)
- `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` (192x192)

## Цвет фона

В конфигурации используется цвет `#5F9EA0` (Cadet Blue) - это бирюзовый цвет как на изображении.
Если нужен другой цвет, измените `adaptive_icon_background` в `pubspec.yaml`.

## Проверка

После установки иконки:
1. Удалите приложение с устройства
2. Установите заново
3. Проверьте иконку на главном экране
