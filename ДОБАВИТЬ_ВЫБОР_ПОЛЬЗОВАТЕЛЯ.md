## 📱 Как это работает

### При создании задачи:

1. **Загружаются все пользователи** из базы данных

- Текущий пользователь помечен как **(Я)** и выделен синим цветом
- Показывается имя пользователя или телефон
- Иконка пользователя рядом с именем

## 📋 SQL функции

### `get_all_users()`

Возвращает всех пользователей из `auth.users`:

```sql
SELECT * FROM get_all_users();
```

Поля:
- `id` - UUID пользователя
- `email` - Email пользователя
- `phone` - Телефон пользователя
- `raw_user_meta_data` - Метаданные (имя, display_name)
- `created_at` - Дата создания

### `get_user_by_id(user_id)`

Возвращает пользователя по ID:

```sql
SELECT * FROM get_user_by_id('uuid-пользователя');
```

## 🐛 Возможные проблемы

### Ошибка: "function get_all_users() does not exist"

**Решение:** Примените SQL функции из `database_users_functions.sql`

### Ошибка: "permission denied for function get_all_users"

**Решение:** Функции уже имеют `GRANT EXECUTE`, но если ошибка сохраняется:

```sql
GRANT EXECUTE ON FUNCTION get_all_users() TO authenticated;
GRANT EXECUTE ON FUNCTION get_user_by_id(UUID) TO authenticated;
```

### Не загружаются пользователи

**Решение:** Проверьте логи в консоли приложения и выполните:

```sql
-- Проверить пользователей
SELECT * FROM auth.users;

-- Проверить функцию
SELECT * FROM get_all_users();
```
