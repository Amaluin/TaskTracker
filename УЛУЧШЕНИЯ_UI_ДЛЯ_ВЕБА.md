# Улучшения UI для веб-версии

## Что изменено

Увеличены размеры кнопок, текстов и интерактивных элементов для более удобного использования веб-версии приложения.

## Основные изменения

### 1. Создан новый файл `lib/core/responsive_sizes.dart`
- Утилита для адаптивных размеров UI элементов
- Автоматически определяет платформу (веб/мобильная)
- Увеличивает размеры на 30-40% для веба

### 2. Обновлен `lib/main.dart`
**Увеличены размеры:**
- Тексты: +30% (14px → 18px, 16px → 20px, 20px → 26px)
- Иконки: +30% (20px → 26px, 24px → 28px)
- Кнопки: высота 48px → 56px, padding увеличен
- Поля ввода: padding увеличен, border 2px → 3px
- Радиусы скругления: +20-25%
- FAB (кнопка создания задачи): увеличены размеры и отступы

### 3. Обновлен `lib/widgets/task_card.dart`
**Увеличены размеры:**
- Заголовки задач: 16px → 20px
- Описания: 14px → 18px
- Метки статуса/приоритета: 12px → 16px
- Иконки: 20px → 26px
- Отступы между элементами: +20-25%
- Границы карточек: 2px → 3px
- Меню действий: размер иконок и текста увеличен

### 4. Обновлен `lib/widgets/kanban_column.dart`
**Увеличены размеры:**
- Заголовки колонок: 16px → 20px
- Счетчики задач: 14px → 18px
- Иконки статусов: 20px → 26px
- Пустое состояние: иконка 48px → 62px
- Границы колонок: 1.5px → 2px, при hover 3px → 4px
- Отступы: увеличены на 20-25%

### 5. Обновлен `lib/widgets/draggable_task_card.dart`
**Увеличены размеры:**
- Все текстовые элементы: +30%
- Иконки: +30%
- Отступы и padding: +20-25%
- Границы: 2px → 3px
- Эффект при перетаскивании: более заметный

## Как это работает

Приложение автоматически определяет платформу через `kIsWeb` из `package:flutter/foundation.dart`:
- **На мобильных устройствах (iOS/Android)**: используются **стандартные размеры** (без изменений)
- **В веб-браузере**: все размеры **автоматически увеличиваются** на 25-40%

### Пример кода:
```dart
final isWeb = kIsWeb;

// Размер текста
fontSize: isWeb ? 20 : 16  // Веб: 20px, Мобильный: 16px (стандарт)

// Padding
padding: EdgeInsets.all(isWeb ? 20 : 16)  // Веб: 20px, Мобильный: 16px (стандарт)
```

**Важно:** На смартфонах размеры остаются прежними, увеличение применяется только для веба!
