ШАГ 1: ПРИМЕНИТЬ ПОЛНУЮ ПЕРЕСБОРКУ (1 минута)
═══════════════════════════════════════════════════════════

1. Откройте: https://studio.bike53.ru
2. SQL Editor → New query
3. Откройте файл: ПОЛНАЯ_ПЕРЕСБОРКА.sql
4. Скопируйте ВСЁ содержимое (Ctrl+A, Ctrl+C)
5. Вставьте в Supabase (Ctrl+V)
6. Нажмите: Run (или Ctrl+Enter)
7. Дождитесь сообщения: "✓ БАЗА ДАННЫХ ПЕРЕСОЗДАНА!"

Что будет создано:
  ✓ user_profiles (с правильными ключами)
  ✓ tasks (с UUID user_id → auth.users)
  ✓ task_reminders
  ✓ task_status_history
  ✓ Все функции и триггеры
  ✓ Все представления
  ✓ Все RLS политики

ПРОВЕРКА В SUPABASE STUDIO
═══════════════════════════════════════════════════════════

После Шага 1 проверьте в Supabase Studio:

1. Table Editor:
   ✓ user_profiles существует
   ✓ tasks существует
   ✓ task_reminders существует
   ✓ task_status_history существует

2. SQL Editor → выполните:
   
   -- Проверка внешнего ключа
   SELECT
     ccu.table_schema || '.' || ccu.table_name
   FROM information_schema.table_constraints AS tc
   JOIN information_schema.constraint_column_usage AS ccu
     ON ccu.constraint_name = tc.constraint_name
   WHERE tc.table_name = 'tasks'
     AND tc.constraint_name = 'tasks_user_id_fkey';
   
   Должно вернуть: auth.users

3. Authentication → Users:
   ✓ После регистрации появятся пользователи
