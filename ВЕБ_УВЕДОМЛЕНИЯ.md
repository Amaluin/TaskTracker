Добавлена поддержка нативных браузерных уведомлений для веб-версии приложения.

- `lib/services/web_notification_service.dart` - сервис веб-уведомлений

- Обновлен `lib/services/notification_service.dart` - использует веб-сервис

---

## 🚀 Как это работает

### 1. Запрос разрешения

При первом запуске приложение запросит разрешение на показ уведомлений:

```
┌─────────────────────────────────────┐
│ app.bike53.ru хочет показывать      │
│ уведомления                         │
│                                     │
│  [Блокировать]  [Разрешить]        │
└─────────────────────────────────────┘
```

Нажмите **"Разрешить"**!

### 2. Планирование уведомлений

Когда вы создаёте задачу с напоминанием:
- Уведомление планируется на указанное время
- Браузер покажет системное уведомление Windows
- Уведомление автоматически закроется через 10 секунд

### 3. Показ уведомления

В указанное время появится уведомление Windows:

```
┌─────────────────────────────────────┐
│ 🔔 Напоминание о задаче             │
│                                     │
│ Купить молоко                       │
│ Срок: сегодня в 18:00              │
└─────────────────────────────────────┘
```

## ⚠️ ВАЖНО

### Браузер должен быть открыт!

Веб-уведомления работают **только когда браузер открыт**:
- ✅ Браузер открыт → уведомления работают
- ❌ Браузер закрыт → уведомления НЕ работают

### Для постоянных уведомлений:

1. **Установите PWA** (Progressive Web App):
   - Откройте https://app.bike53.ru в Chrome
   - Нажмите на иконку "Установить" в адресной строке
   - Приложение установится как обычная программа
   - Уведомления будут работать даже когда основной браузер закрыт

2. **Или используйте Windows приложение**:
   - Соберите нативное Windows приложение
   - Уведомления будут работать всегда

## 🧪 Тестирование

### Проверка разрешений:

1. Откройте https://app.bike53.ru
2. Откройте консоль браузера (F12)
3. Должно быть сообщение:
   ```
   ✅ Разрешение на уведомления получено
   ```

### Проверка уведомления:

1. Создайте задачу с напоминанием через 1 минуту
2. Подождите 1 минуту
3. Должно появиться уведомление Windows

### Если не работает:

1. **Проверьте разрешения браузера**:
   - Chrome: Настройки → Конфиденциальность → Уведомления
   - Убедитесь что app.bike53.ru разрешены

2. **Проверьте настройки Windows**:
   - Параметры → Система → Уведомления
   - Убедитесь что уведомления включены для Chrome

3. **Проверьте консоль**:
   - Откройте F12
   - Посмотрите ошибки

## 📱 PWA (Progressive Web App)

### Установка:

1. Откройте https://app.bike53.ru в Chrome
2. Нажмите на иконку "Установить" (⊕) в адресной строке
3. Нажмите "Установить"
4. Приложение появится на рабочем столе!

### Преимущества PWA:

- ✅ Работает как обычное приложение
- ✅ Уведомления работают в фоне
- ✅ Быстрый запуск
- ✅ Иконка на рабочем столе
- ✅ Работает оффлайн (частично)

## 🐛 Решение проблем

### "Уведомления заблокированы"

1. Откройте настройки сайта в Chrome:
   - Нажмите на замок в адресной строке
   - Настройки сайта
   - Уведомления → Разрешить

2. Перезагрузите страницу

### "Уведомление не показывается"

1. Проверьте консоль (F12)
2. Убедитесь что браузер открыт
3. Проверьте что время напоминания в будущем
4. Проверьте настройки Windows

### "Ошибка: Notification is not defined"

Это нормально для не-веб платформ. Используется заглушка.
