ERROR: cannot alter type of a column used by a view or rule
DETAIL: rule _RETURN on view tasks_with_reminder_count 
        depends on column "user_id"

ПРИЧИНА:
  В базе данных есть представления (views), которые используют
  колонку user_id. PostgreSQL не позволяет изменить тип колонки,
  если на неё ссылаются представления.

РЕШЕНИЕ:
  1. Удалить все представления, зависящие от user_id
  2. Изменить тип колонки user_id
  3. Пересоздать представления

┌───────────────────────────────────────────────────────────┐
│  ЧТО БЫЛО ИСПРАВЛЕНО?                                     │
└───────────────────────────────────────────────────────────┘

В файл database_auth_migration.sql добавлено:

1. В начале миграции (перед ALTER TABLE):
   ✓ DROP VIEW IF EXISTS tasks_with_reminder_count CASCADE;
   ✓ DROP VIEW IF EXISTS overdue_tasks CASCADE;
   ✓ DROP VIEW IF EXISTS upcoming_tasks CASCADE;

2. В конце миграции (после всех изменений):
