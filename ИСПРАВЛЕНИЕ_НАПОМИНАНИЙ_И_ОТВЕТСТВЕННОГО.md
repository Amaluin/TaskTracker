# Исправление напоминаний и выбора ответственного

## Проблемы

1. **Напоминания постоянно загружаются** - крутится индикатор загрузки
2. **Ответственный не выбирается** - показывает "Не назначен" вместо дропдауна

## Решения

### 1. Исправлена загрузка напоминаний

**Проблема:**
Провайдер `RemindersNotifier` инициализировался с `AsyncValue.loading()` и никогда не загружал данные автоматически.

**Было:**
```dart
RemindersNotifier(this._repository) : super(const AsyncValue.loading());
```

**Стало:**
```dart
RemindersNotifier(this._repository) : super(const AsyncValue.data([])) {
  // Инициализируем с пустым списком вместо loading
  loadAllReminders();
}
```

**Результат:**
- ✅ Напоминания загружаются автоматически при инициализации
- ✅ Нет бесконечного индикатора загрузки
- ✅ Показывается "Напоминания не установлены" если их нет

### 2. Добавлен дропдаун для выбора ответственного

**Проблема:**
Ответственный выбирался через диалог, который не работал корректно.

**Было:**
```dart
Container(
  child: Row(
    children: [
      Text(widget.task.assignedToUserName ?? 'Не назначен'),
      IconButton(
        icon: Icon(Icons.edit),
        onPressed: _assignUser, // Открывал диалог
      ),
    ],
  ),
)
```

**Стало:**
```dart
Consumer(
  builder: (context, ref, child) {
    final usersAsync = ref.watch(allUsersProvider);
    return DropdownButton<String?>(
      value: widget.task.assignedToUserId,
      hint: Text('Не назначен'),
      items: [
        DropdownMenuItem(value: null, child: Text('Не назначен')),
        ...users.map((user) => DropdownMenuItem(
          value: user.id,
          child: Text(user.displayText),
        )),
      ],
      onChanged: (newUserId) async {
        // Обновляем задачу
        final updatedTask = widget.task.copyWith(
          assignedToUserId: newUserId ?? '',
          assignedToUserName: userName ?? '',
        );
        await ref.read(tasksProvider.notifier).updateTask(updatedTask);
      },
    );
  },
)
```

**Результат:**
- ✅ Дропдаун с списком всех пользователей
- ✅ Опция "Не назначен" для снятия ответственного
- ✅ Текущий пользователь помечен как "(Я)"
- ✅ Мгновенное обновление при выборе
- ✅ Уведомление о назначении

## Функциональность дропдауна

### Опции в дропдауне:

1. **"Не назначен"** (value: null)
   - Иконка: `person_off_outlined`
   - Снимает ответственного с задачи

2. **Список пользователей**
   - Иконка: `person`
   - Текущий пользователь помечен "(Я)"
   - Цветовое выделение текущего пользователя

### Поведение:

**При выборе пользователя:**
```
1. Находим имя пользователя по ID
2. Обновляем задачу с новым assignedToUserId и assignedToUserName
3. Сохраняем в базу данных
4. Показываем уведомление "Задача назначена пользователю X"
```

**При выборе "Не назначен":**
```
1. Устанавливаем assignedToUserId = ''
2. Устанавливаем assignedToUserName = ''
3. Сохраняем в базу данных
4. Показываем уведомление "Ответственный снят"
```

### Состояния:

**Loading:**
```dart
Container(
  child: Row(
    children: [
      CircularProgressIndicator(),
      Text('Загрузка пользователей...'),
    ],
  ),

```

**Error:**

```dart
  value: widget.task.assignedToUserId,
  items: [...],
  onChanged: (newUserId) { ... },
)
```

## Тестирование

### Напоминания:

1. Откройте детали задачи
2. Секция "Напоминания" должна показывать:
   - "Напоминания не установлены" (если их нет)
   - Список напоминаний (если они есть)
3. Не должно быть бесконечного индикатора загрузки

### Ответственный:

1. Откройте детали задачи
2. Нажмите на дропдаун "Ответственный"
3. Должен открыться список:
   - "Не назначен"
   - Список всех пользователей
   - Текущий пользователь помечен "(Я)"
4. Выберите пользователя
5. Должно появиться уведомление "Задача назначена пользователю X"
6. Задача должна обновиться в базе данных
