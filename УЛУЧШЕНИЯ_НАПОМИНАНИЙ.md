# Улучшения отображения напоминаний

## Что изменено

### 1. Детальный экран задачи (`task_detail_screen.dart`)

Секция напоминаний теперь показывает:

#### Когда напоминаний нет:
- Кликабельная карточка с призывом добавить напоминание
- Иконка и текст "Напоминания не установлены"
- Подсказка "Нажмите, чтобы добавить"

#### Когда есть напоминания:
- **Сортировка** по времени (от ближайших к дальним)
- **Статус напоминания**:
  - Активное предстоящее - синяя рамка с тенью
  - Прошедшее - серый цвет, зачеркнутый текст
  - Выключенное - серая иконка, метка "Выключено"

- **Информация о времени**:
  - Дата и время напоминания
  - Для предстоящих: бейдж с временем до срабатывания
    - "Через X мин" (если меньше часа)
    - "Через X ч" (если меньше суток)
    - "Через X дн" (если больше суток)
  - Для прошедших: метка "Прошло"

- **Тип напоминания**:
  - Иконка будильника для типа "alarm"
  - Иконка уведомления для типа "notification"
  - Текстовая метка типа

- **Визуальные улучшения**:
  - Разные иконки для активных/неактивных/прошедших
  - Цветовое кодирование статуса
  - Тени и рамки для активных напоминаний
  - Плавные переходы при нажатии

- **Кнопка "Управление"** вместо "Добавить" - открывает экран управления напоминаниями

### 2. Обработка ошибок

- Красная карточка с описанием ошибки при проблемах загрузки
- Индикатор загрузки с анимацией

## Как это выглядит

### Активное предстоящее напоминание
```
┌─────────────────────────────────────┐
│ 🔔  15.04.2026 в 14:30    [Через 2ч]│
│     📱 Уведомление                   │
└─────────────────────────────────────┘
```

### Прошедшее напоминание
```
┌─────────────────────────────────────┐
│ 🔕  10.04.2026 в 10:00    Прошло    │
│     📱 Уведомление                   │
└─────────────────────────────────────┘
```

### Выключенное напоминание
```
┌─────────────────────────────────────┐
│ 🔕  20.04.2026 в 18:00              │
│     ⏰ Будильник  [Выключено]        │
└─────────────────────────────────────┘
```

### Нет напоминаний
```
┌─────────────────────────────────────┐
│ 🔔  Напоминания не установлены      │
│     Нажмите, чтобы добавить    →    │
└─────────────────────────────────────┘
```

## Технические детали

### Логика определения статуса
```dart
final isUpcoming = reminder.remindAt.isAfter(DateTime.now());
final isPast = !isUpcoming;
final timeUntil = reminder.remindAt.difference(DateTime.now());
```

### Форматирование времени
- Минуты: `timeUntil.inMinutes < 60`
- Часы: `timeUntil.inHours < 24`
- Дни: `timeUntil.inDays`

### Цветовая схема
- Активное: `Color(0xFF6366F1)` (индиго)
- Неактивное: `Colors.grey`
- Ошибка: `Colors.red`
