# Цветные статусы и приоритеты в формах

## Что добавлено

Цветное оформление чипов (ChoiceChip) для статусов и приоритетов на экранах:
- Создание задачи (CreateTaskScreen)
- Редактирование задачи (TaskDetailScreen)

## Визуальные улучшения

### Статусы

Каждый статус теперь имеет:
- **Цветную иконку** соответствующую статусу
- **Цветной фон** при выборе (alpha: 0.2)
- **Цветную границу** (2px при выборе, 1px без выбора)
- **Тень** с цветом статуса при выборе
- **Жирный текст** при выборе

#### Иконки статусов:
- 🟡 **В ожидании** - `pending_outlined` (янтарный)
- 🟢 **В работе** - `play_circle_outline` (зеленый)
- 🟣 **Отложено** - `pause_circle_outline` (фиолетовый)
- ⚫ **В архиве** - `archive_outlined` (серый)

### Приоритеты

Каждый приоритет теперь имеет:
- **Цветную иконку** со стрелкой
- **Цветной фон** при выборе (alpha: 0.2)
- **Цветную границу** (2px при выборе, 1px без выбора)
- **Тень** с цветом приоритета при выборе
- **Жирный текст** при выборе

#### Иконки приоритетов:
- 🔴 **Высокий** - `arrow_upward` (красный)
- 🟠 **Средний** - `remove` (оранжевый)
- 🟢 **Низкий** - `arrow_downward` (зеленый)

## Технические детали

### ChoiceChip параметры:

```dart
ChoiceChip(
  label: Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      Icon(icon, size: 16, color: isSelected ? color : grey),
      SizedBox(width: 6),
      Text(displayName),
    ],
  ),
  selected: isSelected,
  selectedColor: color.withValues(alpha: 0.2),
  backgroundColor: Colors.white,
  labelStyle: TextStyle(
    color: isSelected ? color : grey,
    fontWeight: isSelected ? FontWeight.w600 : FontWeight.normal,
  ),
  side: BorderSide(
    color: isSelected ? color : Colors.grey.shade300,
    width: isSelected ? 2 : 1,
  ),
  elevation: isSelected ? 2 : 0,
  shadowColor: color.withValues(alpha: 0.3),
)
```

### Функция для иконок статусов:

```dart
IconData _getStatusIcon(String status) {
  switch (status) {
    case AppConstants.statusPending:
      return Icons.pending_outlined;
    case AppConstants.statusAccepted:
      return Icons.play_circle_outline;
    case AppConstants.statusPostponed:
      return Icons.pause_circle_outline;
    case AppConstants.statusArchived:
      return Icons.archive_outlined;
    default:
      return Icons.task_alt;
  }
}
```

## Цветовая схема

### Статусы:
- 🟡 В ожидании: `#F59E0B` (янтарный)
- 🟢 В работе: `#10B981` (зеленый)
- 🟣 Отложено: `#8B5CF6` (фиолетовый)
- ⚫ В архиве: `#6B7280` (серый)

### Приоритеты:
- 🔴 Высокий: `Colors.red`
- 🟠 Средний: `Colors.orange`
- 🟢 Низкий: `Colors.green`

## Преимущества

1. **Визуальная согласованность** - цвета статусов совпадают с карточками задач
2. **Быстрая идентификация** - иконки помогают мгновенно понять значение
3. **Лучший UX** - понятно, что выбрано, что доступно
4. **Современный дизайн** - тени, границы, elevation
5. **Доступность** - цвет + иконка + текст = тройное кодирование информации
