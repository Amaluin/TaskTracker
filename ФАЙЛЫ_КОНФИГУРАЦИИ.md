# 📁 Файлы конфигурации Supabase

Полный список созданных файлов для настройки Supabase с Nginx.

---

## 🔧 Основные конфигурационные файлы

### 1. `nginx-supabase.conf`
**Назначение:** Конфигурация Nginx для проксирования запросов к Supabase

**Что настраивает:**
- SSL терминация для api.bike53.ru и studio.bike53.ru
- Проксирование к Kong API Gateway (порт 8000)
- Проксирование к Supabase Studio (порт 54321)
- Маршрутизация для REST, Auth, Realtime, Storage endpoints
- Security headers
- WebSocket поддержка

**Расположение на сервере:** `/etc/nginx/sites-available/supabase`

---

### 2. `docker-compose.supabase.yml`
**Назначение:** Docker Compose конфигурация для запуска всех сервисов Supabase

**Что запускает:**
- PostgreSQL (база данных)
- Kong (API Gateway)
- GoTrue (аутентификация)
- PostgREST (REST API)
- Realtime (WebSocket)
- Storage (файловое хранилище)
- Studio (админ панель)
- Meta (метаданные для Studio)

**Использование:**
```bash
docker-compose -f docker-compose.supabase.yml up -d
```

---

### 3. `kong.yml`
**Назначение:** Конфигурация Kong API Gateway

**Что настраивает:**
- Маршруты для всех API endpoints
- CORS политики
- Аутентификацию по API ключам
- Consumers (anon, service_role)

**Расположение:** `volumes/kong/kong.yml`

---

### 4. `.env.example`
**Назначение:** Шаблон переменных окружения

**Содержит:**
- Настройки безопасности (пароли, ключи)
- Конфигурацию доменов
- SMTP настройки
- Порты сервисов
- Пути к данным

**Использование:**
```bash
cp .env.example .env
nano .env  # Заполните своими значениями
```

---

## 🤖 Скрипты автоматизации

### 5. `setup-supabase.sh`
**Назначение:** Автоматическая установка всех зависимостей

**Что делает:**
- Устанавливает Docker и Docker Compose
- Устанавливает Nginx
- Устанавливает Certbot
- Получает SSL сертификаты
- Настраивает Nginx конфигурацию
- Настраивает Firewall
- Создает необходимые директории

**Использование:**
```bash
chmod +x setup-supabase.sh
sudo bash setup-supabase.sh
```

---

### 6. `generate-jwt.sh`
**Назначение:** Генерация JWT токенов для Supabase

**Что генерирует:**
- JWT Secret
- Anon Key
- Service Role Key
- Authenticated Key

**Результат:** Создает файл `jwt-keys.txt` с ключами

**Использование:**
```bash
chmod +x generate-jwt.sh
bash generate-jwt.sh
```

---

### 7. `monitor-supabase.sh`
**Назначение:** Мониторинг состояния всех сервисов

**Что проверяет:**
- Статус Docker контейнеров
- Использование ресурсов (CPU, RAM)
- Открытые порты
- Статус Nginx
- SSL сертификаты (срок действия)
- API endpoints (доступность)
- Дисковое пространство
- Ошибки в логах
- Подключение к базе данных
- Uptime сервисов

**Использование:**
```bash
chmod +x monitor-supabase.sh
bash monitor-supabase.sh

# Непрерывный мониторинг (обновление каждые 30 сек)
bash monitor-supabase.sh --watch
```

## 🚀 Порядок использования файлов

### Первоначальная установка:

1. **Скопируйте все файлы** на сервер
2. **Запустите** `setup-supabase.sh` (автоматическая установка)
3. **Запустите** `generate-jwt.sh` (генерация ключей)
4. **Создайте** `.env` из `.env.example` и заполните
5. **Обновите** `docker-compose.supabase.yml` с ключами
6. **Запустите** `docker-compose -f docker-compose.supabase.yml up -d`
7. **Проверьте** с помощью `monitor-supabase.sh`

### Ежедневное использование:

- **Мониторинг:** `bash monitor-supabase.sh`
- **Логи:** `docker-compose -f docker-compose.supabase.yml logs -f`
- **Перезапуск:** `docker-compose -f docker-compose.supabase.yml restart`

### Справка:

- **Полная документация:** `SUPABASE_README.md`
- **Быстрые команды:** `QUICK_START.md`
- **Пошаговая инструкция:** `БЫСТРЫЙ_СТАРТ.md`
- **Чеклист:** `DEPLOYMENT_CHECKLIST.md`
