# Новые функции приложения

## Назначение ответственного и управление задачами

### 1. Назначение ответственного
- В деталях задачи появился раздел "Ответственный"
- Можно назначить пользователя, ответственного за выполнение задачи
- Можно снять ответственного с задачи
- Имя ответственного отображается в карточке задачи

### 2. Принятие задачи
- Если задача назначена на пользователя, появляется кнопка "Принять задачу"
- При принятии задачи:
  - Статус автоматически меняется на "В работе"
  - Создается напоминание за 1 час до срока выполнения (если срок установлен)
  - Отправляется уведомление о создании напоминания

### 3. Отложение задачи
- Любую задачу можно отложить с помощью кнопки "Отложить задачу"
- При отложении:
  - Выбирается дата и время отложения через русский календарь и iOS-стиль время
  - Статус автоматически меняется на "Отложено"
  - Создается напоминание на выбранное время
  - Дата отложения отображается в карточке задачи

### 4. Адаптивный дизайн
- **Мобильная версия**: список задач с карточками
- **Веб-версия** (>900px): Kanban-доска с 4 колонками
  - Drag & Drop между колонками для изменения статуса
  - Уникальные цвета для каждого статуса:
    - В ожидании: Янтарный
    - В работе: Синий
    - Отложено: Фиолетовый
    - В архиве: Серый

### 5. Русская локализация
- Весь интерфейс переведен на русский язык
- Календарь отображается на русском
- Время выбирается через iOS-стиль барабаны (часы и минуты)

### 6. Дизайн в стиле глассморфизм
- Полупрозрачные карточки с эффектом размытия
- Скругленные углы
- Современный минималистичный дизайн
- Цветовая схема: индиго/фиолетовый (#6366F1)

## Обновление базы данных

Для работы новых функций необходимо выполнить SQL-миграцию из файла `database_migration.sql` в вашей Supabase консоли.

Новые поля в таблице `tasks`:
- `assigned_to_user_id` - ID ответственного пользователя
- `assigned_to_user_name` - Имя ответственного пользователя
- `postponed_until` - Дата и время отложения задачи
