Если вы получили ошибку:
  "relation public.user_profiles does not exist"

Это значит, что вы запустили скрипты в неправильном порядке.
Откройте файл ПРАВИЛЬНЫЙ_ПОРЯДОК.txt и следуйте инструкциям.

┌───────────────────────────────────────────────────────────┐
│  ШАГ 1: ПРИМЕНИТЬ МИГРАЦИЮ БД (5 минут)                  │
└───────────────────────────────────────────────────────────┘

1. Откройте браузер: https://studio.bike53.ru
2. Войдите в Supabase Studio
3. Слева выберите: SQL Editor
4. Нажмите: New query
5. Откройте файл: database_auth_migration.sql
6. Скопируйте ВСЁ содержимое файла
7. Вставьте в редактор Supabase
8. Нажмите: Run (или Ctrl+Enter)
9. Дождитесь сообщения: "Миграция завершена!"

⚠️  ВАЖНО: Если у вас есть существующие задачи, они будут
    удалены, так как старый формат user_id несовместим с новым.

┌───────────────────────────────────────────────────────────┐
│  ШАГ 2: НАСТРОИТЬ SUPABASE AUTH (2 минуты)               │
└───────────────────────────────────────────────────────────┘

1. В Supabase Studio слева выберите: Authentication
2. Перейдите на вкладку: Settings
3. Найдите: Enable email confirmations
4. Установите: OFF (выключено)
5. Найдите: Enable email signup
6. Установите: ON (включено)
7. Нажмите: Save (если есть кнопка)

┌───────────────────────────────────────────────────────────┐
│  ШАГ 3: ЗАПУСТИТЬ ПРИЛОЖЕНИЕ (1 минута)                  │
└───────────────────────────────────────────────────────────┘

Откройте терминал в папке проекта и выполните:

    flutter run

Или запустите через IDE (VS Code / Android Studio)

┌───────────────────────────────────────────────────────────┐
│  ШАГ 4: ПРОТЕСТИРОВАТЬ (5 минут)                         │
└───────────────────────────────────────────────────────────┘

ТЕСТ 1: РЕГИСТРАЦИЯ
───────────────────
1. Откройте приложение
2. Нажмите: "Зарегистрироваться"
3. Заполните форму:
   Имя:      Тест
   Телефон:  79001234567
   Пароль:   test123
   Повтор:   test123
4. Нажмите: "Зарегистрироваться"
5. Должно появиться: "Регистрация успешна!"

ТЕСТ 2: ВХОД
────────────
1. На экране входа введите:
   Телефон:  79001234567
   Пароль:   test123
2. Нажмите: "Войти"
3. Должен открыться: Список задач

ТЕСТ 3: СОЗДАНИЕ ЗАДАЧИ
────────────────────────
1. Нажмите: "Новая задача"
2. Заполните:
   Название:  Тестовая задача
   Описание:  Проверка авторизации
3. Нажмите: "Сохранить задачу"
4. Задача должна появиться в списке

ТЕСТ 4: ПРОВЕРКА ПРОФИЛЯ
─────────────────────────
1. Внизу нажмите: "Настройки"
2. Должно отображаться:
   - Ваше имя: Тест
   - Телефон: +79001234567
   - Кнопка "Выйти"

ТЕСТ 5: ВЫХОД
─────────────
1. В настройках нажмите: "Выйти"
2. Подтвердите выход
3. Должен открыться: Экран входа

ТЕСТ 6: ИЗОЛЯЦИЯ ДАННЫХ
────────────────────────
1. Зарегистрируйте второго пользователя:
   Имя:      Тест2
   Телефон:  79009999999
   Пароль:   test456
2. Войдите под вторым пользователем
3. Создайте задачу
4. Выйдите и войдите под первым пользователем
5. Проверьте: задачи второго пользователя НЕ видны

│  🔧 ВОЗМОЖНЫЕ ПРОБЛЕМЫ                                    │
└───────────────────────────────────────────────────────────┘

ПРОБЛЕМА: "User not authenticated"
РЕШЕНИЕ:  Выйдите и войдите снова

ПРОБЛЕМА: "Invalid login credentials"
РЕШЕНИЕ:  Проверьте правильность телефона и пароля

ПРОБЛЕМА: "User already registered"
РЕШЕНИЕ:  Этот телефон уже зарегистрирован, используйте вход

ПРОБЛЕМА: Задачи не создаются
РЕШЕНИЕ:  
  1. Проверьте, что миграция БД применена
  2. Проверьте логи в Supabase Studio → Logs
  3. Убедитесь, что пользователь авторизован

ПРОБЛЕМА: Не видно задач после входа
РЕШЕНИЕ:  
  1. Проверьте RLS политики в Supabase Studio
  2. Проверьте, что user_id в задачах = auth.uid()
  3. Посмотрите логи в Supabase Studio → Logs

ПРОБЛЕМА: Ошибка компиляции Flutter
РЕШЕНИЕ:  
  1. flutter clean
  2. flutter pub get
  3. flutter run
