# 🚀 Начало работы - Пошаговая инструкция

## Ваша текущая ситуация

Вы подключены к серверу и пытаетесь скопировать файлы, но получаете ошибку:
```
cp: cannot stat 'nginx-supabase.conf': No such file or directory
```

**Причина:** Файлы находятся на вашем локальном компьютере, а не на сервере.

---

## ✅ Решение: 3 простых шага

### Шаг 1: Упакуйте файлы на локальном компьютере

#### Вариант A: Автоматическая упаковка (Windows PowerShell)

```powershell
# В директории проекта task_tracker
.\pack-files.ps1
```

Это создаст файл `supabase-config-YYYYMMDD_HHMMSS.zip`

#### Вариант B: Ручная упаковка (Windows)

1. Выделите все файлы:
   - nginx-supabase.conf
   - docker-compose.supabase.yml
   - kong.yml
   - .env.example
   - setup-supabase.sh
   - generate-jwt.sh
   - monitor-supabase.sh
   - Все .md файлы

2. Правой кнопкой → Отправить → Сжатая ZIP-папка

3. Назовите: `supabase-config.zip`

---

### Шаг 2: Загрузите файлы на сервер

#### Вариант A: Через SCP (из PowerShell/CMD)

```powershell
# Загрузите архив
scp supabase-config.zip root@185.225.34.252:/opt/

# Или загрузите файлы напрямую (без архива)
scp nginx-supabase.conf root@185.225.34.252:/opt/supabase/
scp docker-compose.supabase.yml root@185.225.34.252:/opt/supabase/
scp kong.yml root@185.225.34.252:/opt/supabase/
scp .env.example root@185.225.34.252:/opt/supabase/
scp setup-supabase.sh root@185.225.34.252:/opt/supabase/
scp generate-jwt.sh root@185.225.34.252:/opt/supabase/
scp monitor-supabase.sh root@185.225.34.252:/opt/supabase/
```

#### Вариант B: Через WinSCP (GUI)

1. Скачайте WinSCP: https://winscp.net/eng/download.php
2. Установите и запустите
3. Подключитесь:
   - Протокол: SFTP
   - Хост: 185.225.34.252
   - Порт: 22
   - Имя пользователя: root
   - Пароль: ваш пароль
4. Перетащите файлы в `/opt/supabase/`

---

### Шаг 3: Распакуйте и запустите установку на сервере

```bash
# Вы уже подключены к серверу, продолжайте:

# Если загрузили архив:
cd /opt
unzip supabase-config.zip -d supabase
cd supabase

# Если загрузили файлы напрямую:
cd /opt/supabase

# Проверьте наличие файлов
ls -la

# Установите права на выполнение
chmod +x setup-supabase.sh generate-jwt.sh monitor-supabase.sh

# Запустите автоматическую установку
sudo bash setup-supabase.sh
```

## 📋 Полная последовательность команд

### На локальном компьютере (Windows PowerShell):

```powershell
# Перейдите в директорию проекта
cd C:\path\to\task_tracker

# Вариант 1: Загрузите все файлы одной командой
scp nginx-supabase.conf docker-compose.supabase.yml kong.yml .env.example setup-supabase.sh generate-jwt.sh monitor-supabase.sh root@185.225.34.252:/opt/supabase/

# Вариант 2: Создайте и загрузите архив
.\pack-files.ps1
scp supabase-config-*.zip root@185.225.34.252:/opt/
```

### На сервере (уже подключены через SSH):

```bash
# Если загрузили архив:
cd /opt
unzip supabase-config-*.zip -d supabase
cd supabase

# Если загрузили файлы напрямую:
cd /opt/supabase

# Проверьте файлы
ls -la

# Должны увидеть:
# nginx-supabase.conf
# docker-compose.supabase.yml
# kong.yml
# .env.example
# setup-supabase.sh
# generate-jwt.sh
# monitor-supabase.sh

# Установите права
chmod +x setup-supabase.sh generate-jwt.sh monitor-supabase.sh

# Запустите установку
sudo bash setup-supabase.sh

# После установки сгенерируйте JWT ключи
bash generate-jwt.sh

# Создайте .env файл
cp .env.example .env
nano .env
# Заполните значениями из jwt-keys.txt
# Сохраните: Ctrl+X, Y, Enter

# Обновите docker-compose.supabase.yml
nano docker-compose.supabase.yml
# Замените пароли и ключи
# Сохраните: Ctrl+X, Y, Enter

# Создайте директории
mkdir -p volumes/db/data volumes/storage volumes/kong
cp kong.yml volumes/kong/

# Запустите Supabase
docker-compose -f docker-compose.supabase.yml up -d

# Проверьте статус
docker-compose -f docker-compose.supabase.yml ps

# Запустите мониторинг
bash monitor-supabase.sh
```

## 🆘 Если ничего не работает

### Вариант: Используйте содержимое из открытых файлов

У вас открыты файлы в редакторе:
- nginx-supabase.conf
- docker-compose.supabase.yml
- kong.yml
- .env.example
- generate-jwt.sh
- И другие

Просто скопируйте содержимое каждого файла и создайте их на сервере через `nano`:

```bash
# Пример для nginx-supabase.conf
nano /opt/supabase/nginx-supabase.conf

# В nano:
# 1. Вставьте содержимое (Shift+Insert или правая кнопка мыши)
# 2. Сохраните: Ctrl+X
# 3. Подтвердите: Y
# 4. Нажмите: Enter
```
