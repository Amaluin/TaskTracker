# Исправление проблем на Android

## Проблемы
1. ❌ После регистрации открывается экран логина вместо главного экрана
2. ❌ При логине ошибка: "Неверный формат запроса. Возможно, пользователь не подтвержден"

## Решение

### 1. Исправлена навигация после регистрации
Увеличена задержка перед возвратом на главный экран с 300ms до 500ms, чтобы auth listener успел обновить состояние.

### 2. Автоматическое подтверждение пользователей

Выполните SQL скрипт в Supabase SQL Editor:

```bash
# Откройте Supabase Dashboard
# Перейдите в SQL Editor
# Выполните файл: auto_confirm_users_trigger.sql
```

Этот скрипт:
- ✅ Создает триггер для автоматического подтверждения новых пользователей
- ✅ Подтверждает всех существующих пользователей
- ✅ Все новые регистрации будут автоматически подтверждаться

### Альтернативное решение (если триггер не работает)

Выполните скрипт `ПОДТВЕРДИТЬ_ВСЕХ_ПОЛЬЗОВАТЕЛЕЙ.sql` для подтверждения существующих пользователей.

## Проверка

1. Зарегистрируйте нового пользователя
2. После регистрации должен открыться главный экран (не логин)
3. При логине не должно быть ошибок

## Что было изменено

### lib/screens/auth/register_screen.dart
- Увеличена задержка перед навигацией с 300ms до 500ms
- Улучшен комментарий для понимания логики

### auto_confirm_users_trigger.sql (новый файл)
- Триггер для автоматического подтверждения пользователей
- Подтверждение существующих пользователей
