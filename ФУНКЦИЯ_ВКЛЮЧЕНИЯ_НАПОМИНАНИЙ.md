# Функция включения/выключения напоминаний

## Что добавлено

### 1. Переключатель в настройках
В экране настроек (`settings_screen.dart`) добавлен переключатель (SwitchListTile):
- ✅ Включение/выключение напоминаний
- ✅ Визуальная индикация состояния (зелёная/серая иконка)
- ✅ Сохранение настройки в SharedPreferences
- ✅ Отмена всех запланированных уведомлений при выключении

### 2. Проверка настройки при создании напоминаний
В `notification_service.dart` добавлена проверка:
- Перед планированием уведомления проверяется настройка
- Если напоминания отключены, уведомление не создаётся
- Работает для всех типов напоминаний (задачи, отложенные задачи)

## Как использовать

1. Откройте приложение
2. Перейдите в раздел "Настройки" (нижняя панель навигации)
3. В разделе "Уведомления" переключите "Напоминания о задачах"

### При выключении:
- Все запланированные напоминания будут отменены
- Новые напоминания не будут создаваться
- Появится уведомление: "Все напоминания отменены"

### При включении:
- Новые напоминания будут создаваться при добавлении задач
- Появится уведомление: "Напоминания включены"
- Существующие задачи нужно будет переоткрыть для создания напоминаний

## Технические детали

### Хранение настройки
```dart
SharedPreferences: 'notifications_enabled' (bool)
По умолчанию: true
```

### Проверка перед созданием уведомления
```dart
final enabled = await NotificationService().areNotificationsEnabled();
if (!enabled) return; // Не создаём уведомление
```
