## 🔐 Архитектура безопасности

### Поток авторизации
```
┌─────────────────────────────────────────────────────────┐
│ 1. Пользователь вводит телефон: +79001234567           │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 2. Преобразование в email: 79001234567@tasktracker.local│
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 3. Supabase Auth (bcrypt хеширование пароля)           │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 4. Генерация JWT токена (автоматически)                │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 5. Создание профиля через триггер                       │
│    - user_profiles.phone = +79001234567                 │
│    - user_profiles.display_name = Имя пользователя      │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 6. Все запросы используют auth.uid()                    │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 7. RLS политики фильтруют данные по user_id             │
└─────────────────────────────────────────────────────────┘
                         ↓
┌─────────────────────────────────────────────────────────┐
│ 8. Пользователь видит только свои задачи               │
└─────────────────────────────────────────────────────────┘
```

### Уровни защиты

1. **Пароли**: bcrypt хеширование (Supabase)
2. **Токены**: JWT с автоматическим обновлением
3. **RLS**: Row Level Security на уровне БД
4. **Внешние ключи**: Защита целостности данных
5. **Валидация**: На уровне приложения и БД

## 📊 Структура базы данных

### Таблицы

#### auth.users (Supabase)
```sql
id              UUID PRIMARY KEY
email           TEXT UNIQUE
encrypted_password TEXT
raw_user_meta_data JSONB  -- {phone, name, display_name}
created_at      TIMESTAMPTZ
```

#### user_profiles (Новая)
```sql
id              UUID PRIMARY KEY → auth.users(id)
phone           TEXT UNIQUE NOT NULL
display_name    TEXT NOT NULL
avatar_url      TEXT
created_at      TIMESTAMPTZ
updated_at      TIMESTAMPTZ
```

#### tasks (Обновлена)
```sql
id              UUID PRIMARY KEY
user_id         UUID → auth.users(id)  -- Изменено с TEXT
title           TEXT NOT NULL
description     TEXT
status          TEXT NOT NULL
priority        TEXT NOT NULL
due_at          TIMESTAMPTZ
created_at      TIMESTAMPTZ
updated_at      TIMESTAMPTZ
archived_at     TIMESTAMPTZ
```

### RLS Политики

#### tasks
```sql
-- Чтение: только свои задачи
CREATE POLICY "Users can read own tasks"
  ON tasks FOR SELECT
  TO authenticated
  USING (user_id = auth.uid());

-- Создание: только со своим user_id
CREATE POLICY "Users can insert own tasks"
  ON tasks FOR INSERT
  TO authenticated
  WITH CHECK (user_id = auth.uid());

-- Обновление: только свои задачи
CREATE POLICY "Users can update own tasks"
  ON tasks FOR UPDATE
  TO authenticated
  USING (user_id = auth.uid())
  WITH CHECK (user_id = auth.uid());

-- Удаление: только свои задачи
CREATE POLICY "Users can delete own tasks"
  ON tasks FOR DELETE
  TO authenticated
  USING (user_id = auth.uid());
```

## 🔧 Технические детали

### Формат телефона
```dart
// Ввод пользователя
"9001234567"
"89001234567"
"+79001234567"

// Нормализация
"+79001234567"

// Email для Supabase Auth
"79001234567@tasktracker.local"

// Хранение в профиле
"+79001234567"
```

### Получение userId
```dart
// Старый способ (удален)
final prefs = await SharedPreferences.getInstance();
final userId = prefs.getString('user_id');

// Новый способ
final userId = Supabase.instance.client.auth.currentUser?.id;
```

### Проверка авторизации
```dart
// В main.dart
if (Supabase.instance.client.auth.currentSession == null) {
  return const LoginScreen();
}
return const MainScreen();
```

### Выход из системы
```dart
await Supabase.instance.client.auth.signOut();
// Навигация обрабатывается автоматически через EntryWrapper
```
