## 📝 АВТОМАТИЗАЦИЯ (Создать скрипт)

### Для Windows (PowerShell)

Создайте файл `deploy.ps1`:

```powershell
# Сборка
Write-Host "🔨 Сборка приложения..." -ForegroundColor Green
flutter build web --release

if ($LASTEXITCODE -eq 0) {
    Write-Host "✓ Сборка завершена" -ForegroundColor Green
    
    # Загрузка
    Write-Host "📤 Загрузка на сервер..." -ForegroundColor Green
    scp -r build/web/* root@185.225.34.252:/var/www/app.bike53.ru/
    
    if ($LASTEXITCODE -eq 0) {
        Write-Host "✓ Загрузка завершена" -ForegroundColor Green
        Write-Host "🎉 Приложение опубликовано: https://app.bike53.ru" -ForegroundColor Cyan
    } else {
        Write-Host "✗ Ошибка загрузки" -ForegroundColor Red
    }
} else {
    Write-Host "✗ Ошибка сборки" -ForegroundColor Red
}
```

Запуск:
```powershell
.\deploy.ps1
```

### Для Linux/Mac (Bash)

Создайте файл `deploy.sh`:

```bash
#!/bin/bash

# Сборка
echo "🔨 Сборка приложения..."
flutter build web --release

if [ $? -eq 0 ]; then
    echo "✓ Сборка завершена"
    
    # Загрузка
    echo "📤 Загрузка на сервер..."
    scp -r build/web/* root@185.225.34.252:/var/www/app.bike53.ru/
    
    if [ $? -eq 0 ]; then
        echo "✓ Загрузка завершена"
        echo "🎉 Приложение опубликовано: https://app.bike53.ru"
    else
        echo "✗ Ошибка загрузки"
    fi
else
    echo "✗ Ошибка сборки"
fi
```

Запуск:
```bash
chmod +x deploy.sh
./deploy.sh
```

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Приложение не обновляется

```bash
# Очистить кэш на сервере
ssh root@185.225.34.252
rm -rf /var/www/app.bike53.ru/*

# Загрузить заново
scp -r build/web/* root@185.225.34.252:/var/www/app.bike53.ru/
```

### Ошибка 404

```bash
# Проверить файлы на сервере
ssh root@185.225.34.252
ls -la /var/www/app.bike53.ru/

# Должны быть файлы: index.html, main.dart.js, flutter.js и т.д.
```

### Ошибка прав доступа

```bash
ssh root@185.225.34.252
chown -R www-data:www-data /var/www/app.bike53.ru
chmod -R 755 /var/www/app.bike53.ru
```

### Белый экран

1. Откройте консоль браузера (F12)
2. Посмотрите ошибки
3. Проверьте что `lib/core/constants.dart` содержит правильный URL Supabase
