# Исправление проблемы с отображением пользователей

## Проблема
При создании задачи не показывается текущий пользователь в выпадающем списке.

## Причины
1. Функция `get_all_users()` не создана в базе данных
2. Нет прав на выполнение функции
3. Ошибка при получении данных из auth.users

## Решение

### Шаг 1: Выполните SQL скрипт
Выполните файл `ПРОВЕРКА_ФУНКЦИЙ_ПОЛЬЗОВАТЕЛЕЙ.sql` в вашей базе данных Supabase:

```bash
# Через psql
psql -h localhost -U postgres -d postgres -f ПРОВЕРКА_ФУНКЦИЙ_ПОЛЬЗОВАТЕЛЕЙ.sql

# Или через Supabase Studio
# 1. Откройте https://studio.bike53.ru
# 2. Перейдите в SQL Editor
# 3. Скопируйте содержимое файла ПРОВЕРКА_ФУНКЦИЙ_ПОЛЬЗОВАТЕЛЕЙ.sql
# 4. Нажмите "Run"
```

### Шаг 2: Проверьте результат
После выполнения скрипта вы должны увидеть:
- Список созданных функций
- Список пользователей из базы данных
- Права доступа к функциям

### Шаг 3: Перезапустите приложение
```bash
flutter clean
flutter pub get
flutter run
```

## Альтернативное решение (если функции не работают)

Если RPC функции не работают, можно использовать альтернативный подход - хранить информацию о пользователях в отдельной таблице `user_profiles`:

```sql
-- Создать таблицу профилей
CREATE TABLE IF NOT EXISTS user_profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email TEXT NOT NULL,
  phone TEXT,
  name TEXT,
  display_name TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- Включить RLS
ALTER TABLE user_profiles ENABLE ROW LEVEL SECURITY;

-- Политики доступа
CREATE POLICY "Пользователи могут видеть все профили"
  ON user_profiles FOR SELECT
  TO authenticated
  USING (true);

CREATE POLICY "Пользователи могут обновлять свой профиль"
  ON user_profiles FOR UPDATE
  TO authenticated
  USING (auth.uid() = id);
```

Затем измените `UserRepository.getAllUsers()`:
```dart
Future<List<UserModel>> getAllUsers() async {
  try {
    final response = await _client
        .from('user_profiles')
        .select()
        .order('created_at', ascending: false);
    
    return (response as List)
        .map((json) => UserModel.fromJson(json))
        .toList();
  } catch (e) {
    print('❌ Ошибка: $e');
    final currentUser = await getCurrentUser();
    return currentUser != null ? [currentUser] : [];
  }
}
```
