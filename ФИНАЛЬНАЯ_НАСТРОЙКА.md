## 📋 Осталось сделать:

### Шаг 1: Настроить базу данных (5 минут)

#### 1.1 Откройте Supabase Studio

```
https://studio.bike53.ru
```

Войдите в админ панель (используйте учетные данные, если настроена аутентификация).

#### 1.2 Перейдите в SQL Editor

1. В левом меню найдите **SQL Editor**
2. Нажмите **New query**

#### 1.3 Выполните скрипт создания БД

1. Откройте файл `database_schema.sql` в вашем редакторе
2. Скопируйте **всё** содержимое (Ctrl+A, Ctrl+C)
3. Вставьте в SQL Editor в Studio (Ctrl+V)
4. Нажмите **Run** (или Ctrl+Enter)
5. Дождитесь выполнения (5-10 секунд)

#### 1.4 Проверьте результат

Вы должны увидеть сообщение:
```
============================================
Схема базы данных успешно создана!
============================================
Таблицы: 3
Индексы: 20+
Функции: 5
Представления: 3
============================================
```

#### 1.5 Проверьте таблицы

1. Перейдите в **Table Editor** (левое меню)
2. Убедитесь, что созданы таблицы:
   - ✅ **tasks**
   - ✅ **task_reminders**
   - ✅ **task_status_history**

### Шаг 2: Получить Anon Key (2 минуты)

#### 2.1 Откройте настройки API

1. В Supabase Studio перейдите в **Settings** (левое меню)
2. Выберите **API**

#### 2.2 Скопируйте Anon Key

1. Найдите раздел **Project API keys**
2. Скопируйте ключ **anon** (public)
3. Сохраните его - понадобится в следующем шаге

**Пример Anon Key:**
```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZSIsInJlZiI6InByb2plY3QiLCJyb2xlIjoiYW5vbiIsImlhdCI6MTYxNjE2MTYxNiwiZXhwIjoxOTMxNzM3NjE2fQ.example
```

#### 2.3 Проверьте URL

Убедитесь, что **URL** в настройках API:
```
https://api.bike53.ru
```

```sql
SELECT 
  COUNT(*) as total,
  COUNT(*) FILTER (WHERE status = 'pending') as pending,
```

## 🆘 Troubleshooting

### Проблема: Не могу войти в Studio

**Решение:**
1. Проверьте, что Studio доступен: `curl https://studio.bike53.ru`
2. Проверьте логи: `docker-compose -f docker-compose.supabase.yml logs studio`
3. Перезапустите: `docker-compose -f docker-compose.supabase.yml restart studio`

### Проблема: Ошибка "Invalid API key"

**Решение:**
1. Убедитесь, что скопировали правильный Anon Key из Studio
2. Проверьте, что нет лишних пробелов в начале/конце ключа
3. Убедитесь, что URL правильный: `https://api.bike53.ru`

### Проблема: Таблицы не создаются

**Решение:**
1. Проверьте логи в SQL Editor
2. Убедитесь, что скопировали весь скрипт `database_schema.sql`
3. Попробуйте выполнить скрипт по частям

### Проблема: Flutter приложение не подключается

**Решение:**
1. Проверьте, что `supabaseUrl` правильный: `https://api.bike53.ru`
2. Проверьте, что `supabaseAnonKey` скопирован полностью
3. Выполните `flutter clean` и `flutter pub get`
4. Перезапустите приложение

### Проблема: Ошибка CORS

**Решение:**
CORS уже настроен в Kong конфигурации. Если проблема сохраняется:
1. Проверьте `kong.yml` в `volumes/kong/`
2. Перезапустите Kong: `docker-compose -f docker-compose.supabase.yml restart kong`
