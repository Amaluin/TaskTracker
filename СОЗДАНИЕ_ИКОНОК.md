# 🎨 СОЗДАНИЕ ИКОНОК ДЛЯ ПРИЛОЖЕНИЯ

## 📱 Что нужно

Для Task Tracker (планировщик задач) подойдут иконки с:
- ✅ Галочкой (checkmark)
- 📋 Списком задач (checklist)
- ✓ Галочкой в круге
- 📝 Блокнотом

---

## 🚀 АВТОМАТИЧЕСКАЯ ГЕНЕРАЦИЯ (Рекомендуется)

### Шаг 1: Установить flutter_launcher_icons

Добавьте в `pubspec.yaml`:

```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.13.1

flutter_launcher_icons:
  android: true
  ios: true
  web:
    generate: true
    image_path: "assets/icon.png"
    background_color: "#6366F1"
    theme_color: "#6366F1"
  image_path: "assets/icon.png"
  adaptive_icon_background: "#6366F1"
  adaptive_icon_foreground: "assets/icon.png"
```

### Шаг 2: Подготовить иконку

1. Скачайте иконку размером **1024x1024** (PNG с прозрачным фоном)
2. Создайте папку `assets` в корне проекта
3. Сохраните иконку как `assets/icon.png`

### Шаг 3: Сгенерировать иконки

```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

Готово! Иконки автоматически созданы для всех платформ! 🎉

## 📋 БЫСТРЫЙ СТАРТ

### 1. Скачать готовую иконку

Рекомендую эти иконки с Flaticon:

**Поиск на Flaticon:**
- "checklist icon purple"
- "task list icon"
- "todo icon gradient"

**Фильтры:**
- Цвет: Фиолетовый (#6366F1)
- Стиль: Flat, Modern
- Формат: PNG

### 2. Подготовить иконку

```bash
# Создать папку assets
mkdir assets

# Скопировать иконку
# Переименовать в icon.png
# Размер должен быть 1024x1024
```

### 3. Настроить pubspec.yaml

```yaml
flutter:
  assets:
    - assets/icon.png

dev_dependencies:
  flutter_launcher_icons: ^0.13.1

flutter_launcher_icons:
  android: true
  ios: true
  web:
    generate: true
    image_path: "assets/icon.png"
    background_color: "#6366F1"
    theme_color: "#6366F1"
  image_path: "assets/icon.png"
  adaptive_icon_background: "#6366F1"
  adaptive_icon_foreground: "assets/icon.png"
```

### 4. Сгенерировать

```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

### 5. Пересобрать и опубликовать

```bash
# Собрать
flutter build web --release

# Опубликовать
.\deploy.ps1
```

## 💡 СОВЕТЫ

1. **Используйте простую иконку** - она должна быть узнаваемой даже в маленьком размере
2. **Избегайте мелких деталей** - они потеряются на маленьких размерах
3. **Используйте контрастные цвета** - иконка должна выделяться
4. **Тестируйте на разных фонах** - светлом и темном
5. **Используйте прозрачный фон** для адаптивных иконок
