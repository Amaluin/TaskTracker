# 📤 Инструкция по загрузке файлов на сервер

## Проблема
Вы видите ошибку: `cp: cannot stat 'nginx-supabase.conf': No such file or directory`

Это означает, что файлы конфигурации находятся на вашем локальном компьютере, а не на сервере.

---

## ✅ Решение: Загрузите файлы на сервер

### Вариант 1: Использование SCP (рекомендуется)

#### На Windows (PowerShell или CMD):

```powershell
# Перейдите в директорию проекта
cd C:\path\to\task_tracker

# Загрузите все файлы конфигурации на сервер
scp nginx-supabase.conf root@185.225.34.252:/opt/supabase/
scp docker-compose.supabase.yml root@185.225.34.252:/opt/supabase/
scp kong.yml root@185.225.34.252:/opt/supabase/
scp .env.example root@185.225.34.252:/opt/supabase/
scp setup-supabase.sh root@185.225.34.252:/opt/supabase/
scp generate-jwt.sh root@185.225.34.252:/opt/supabase/
scp monitor-supabase.sh root@185.225.34.252:/opt/supabase/
scp *.md root@185.225.34.252:/opt/supabase/
```

#### Или загрузите все файлы одной командой:

```powershell
scp nginx-supabase.conf docker-compose.supabase.yml kong.yml .env.example setup-supabase.sh generate-jwt.sh monitor-supabase.sh *.md root@185.225.34.252:/opt/supabase/
```

### Вариант 2: Использование WinSCP (GUI)

1. **Скачайте WinSCP**: https://winscp.net/eng/download.php
2. **Установите и запустите**
3. **Подключитесь к серверу:**
   - Протокол: SFTP
   - Хост: 185.225.34.252
   - Порт: 22
   - Имя пользователя: root
   - Пароль: ваш пароль
4. **Создайте директорию** `/opt/supabase` на сервере
5. **Перетащите файлы** из локальной папки в `/opt/supabase/`

---

### Вариант 3: Использование FileZilla

1. **Скачайте FileZilla**: https://filezilla-project.org/
2. **Установите и запустите**
3. **Подключитесь:**
   - Хост: sftp://185.225.34.252
   - Имя пользователя: root
   - Пароль: ваш пароль
   - Порт: 22
4. **Загрузите файлы** в `/opt/supabase/`

---

### Вариант 4: Создание файлов напрямую на сервере

Если у вас проблемы с загрузкой, создайте файлы напрямую на сервере:

```bash
# Подключитесь к серверу
ssh root@185.225.34.252

# Создайте директорию
mkdir -p /opt/supabase
cd /opt/supabase

# Создайте файл nginx-supabase.conf
nano nginx-supabase.conf
# Скопируйте содержимое из локального файла и вставьте
# Сохраните: Ctrl+X, затем Y, затем Enter

# Повторите для остальных файлов
nano docker-compose.supabase.yml
nano kong.yml
nano .env.example
nano setup-supabase.sh
nano generate-jwt.sh
nano monitor-supabase.sh
```

## ✅ Проверка загрузки

После загрузки файлов на сервер, проверьте:

```bash
# Подключитесь к серверу
ssh root@185.225.34.252

# Перейдите в директорию
cd /opt/supabase

# Проверьте наличие файлов
ls -la

# Должны увидеть:
# nginx-supabase.conf
# docker-compose.supabase.yml
# kong.yml
# .env.example
# setup-supabase.sh
# generate-jwt.sh
# monitor-supabase.sh
```

## 💡 Совет

Для удобства создайте архив со всеми файлами:

### На Windows:

```powershell
# В директории проекта
Compress-Archive -Path nginx-supabase.conf,docker-compose.supabase.yml,kong.yml,.env.example,setup-supabase.sh,generate-jwt.sh,monitor-supabase.sh,*.md -DestinationPath supabase-config.zip

# Загрузите архив
scp supabase-config.zip root@185.225.34.252:/opt/

# На сервере распакуйте
ssh root@185.225.34.252
cd /opt
unzip supabase-config.zip -d supabase
cd supabase
```

## 🆘 Если ничего не работает

Создайте файлы вручную на сервере, используя содержимое из открытых файлов в редакторе.

### Пример для nginx-supabase.conf:

```bash
ssh root@185.225.34.252
mkdir -p /opt/supabase
cd /opt/supabase
nano nginx-supabase.conf
```

Затем скопируйте содержимое из файла `nginx-supabase.conf` в вашем редакторе и вставьте в nano:
- Правой кнопкой мыши → Вставить
- Или Shift+Insert

Сохраните:
- Ctrl+X
- Y
- Enter

Повторите для всех файлов.
