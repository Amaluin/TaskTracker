# Адаптивный Kanban с гибкими колонками

## Что изменено

Kanban доска теперь адаптируется к ширине экрана, колонки автоматически изменяют свою ширину.

## Как работает

### Расчет ширины колонок

```dart
// Доступная ширина = ширина экрана - отступы - промежутки между колонками
final totalPadding = 24.0 * 2; // padding слева и справа
final columnSpacing = 16.0; // отступ между колонками
final totalSpacing = columnSpacing * (количество_колонок - 1);
final availableWidth = constraints.maxWidth - totalPadding - totalSpacing;
final columnWidth = availableWidth / количество_колонок;
```

### Ограничения ширины

- **Минимальная ширина**: 280px (для читаемости)
- **Максимальная ширина**: без ограничений (расширяется на весь экран)
- **Фиксированная ширина при скролле**: 320px

### Режимы отображения

#### 1. Широкий экран (все колонки помещаются)
- Колонки растягиваются равномерно на всю ширину
- Минимальная ширина 280px на колонку
- Вертикальный скролл для задач
- Нет горизонтального скролла

**Примеры:**
- Экран 3840px (4K): 4 колонки × ~940px = максимальное использование пространства
- Экран 2560px: 4 колонки × ~620px = широкие колонки
- Экран 1920px: 4 колонки × ~460px = комфортная ширина
- Экран 1440px: 4 колонки × ~340px = стандартная ширина
- Экран 1200px: 4 колонки × ~280px = минимальная ширина

#### 2. Узкий экран (колонки не помещаются)
- Колонки фиксированной ширины 320px
- Горизонтальный скролл
- Вертикальный скролл для задач

**Примеры:**
- Экран 900px: горизонтальный скролл
- Планшет: горизонтальный скролл

## Технические детали

### LayoutBuilder

Используется `LayoutBuilder` для получения доступной ширины:

```dart
LayoutBuilder(
  builder: (context, constraints) {
    // constraints.maxWidth - доступная ширина
    final columnWidth = calculateWidth(constraints.maxWidth);
    // ...
  },
)
```

### Динамические отступы

```dart
Container(
  width: needsScroll ? 320 : clampedWidth,
  margin: EdgeInsets.only(
    right: status != AppConstants.allStatuses.last ? 16 : 0,
  ),
  child: KanbanColumn(...),
)
```

### Условный скролл

```dart
if (needsScroll) {
  return SingleChildScrollView(
    scrollDirection: Axis.horizontal,
    child: columnsRow,
  );
} else {
  return SingleChildScrollView(
    child: columnsRow,
  );
}
```

## Изменения в файлах

### 1. lib/screens/tasks/task_list_screen.dart

**Было:**
```dart
SingleChildScrollView(
  scrollDirection: Axis.horizontal,
  child: Row(
    children: AppConstants.allStatuses.map((status) {
      return KanbanColumn(...); // фиксированная ширина в KanbanColumn
    }).toList(),
  ),
)
```

**Стало:**
```dart
LayoutBuilder(
  builder: (context, constraints) {
    final columnWidth = calculateDynamicWidth(constraints);
    
    return needsScroll 
      ? SingleChildScrollView(
          scrollDirection: Axis.horizontal,
          child: Row(
            children: columns.map((status) {
              return Container(
                width: columnWidth, // динамическая ширина
                child: KanbanColumn(...),
              );
            }).toList(),
          ),
        )
      : SingleChildScrollView(
          child: Row(children: columns),
        );
  },
)
```

### 2. lib/widgets/kanban_column.dart

**Было:**
```dart
AnimatedContainer(
  width: 320, // фиксированная ширина
  margin: const EdgeInsets.symmetric(horizontal: 8),
  // ...
)
```

**Стало:**
```dart
AnimatedContainer(
  // width убрана - берется из родителя
  margin: const EdgeInsets.symmetric(horizontal: 0),
  // ...
)
```

## Преимущества

### 1. Адаптивность
- ✅ Автоматическая подстройка под любой экран
- ✅ Оптимальное использование пространства
- ✅ Нет пустого места по бокам
- ✅ Колонки растягиваются на всю ширину экрана

### 2. Удобство
- ✅ На широких экранах - максимум информации видно
- ✅ На узких экранах - горизонтальный скролл
- ✅ Колонки всегда читаемого размера (минимум 280px)
- ✅ На 4K мониторах - очень широкие удобные колонки

### 3. Производительность
- ✅ Пересчет только при изменении размера
- ✅ Плавные анимации (AnimatedContainer)
- ✅ Эффективный рендеринг

### 4. UX
- ✅ Интуитивно понятное поведение
- ✅ Нет неожиданных скроллов на широких экранах
- ✅ Удобный скролл на узких экранах
- ✅ Максимальное использование доступного пространства

## Тестирование

Проверьте на разных разрешениях:

1. **8K (7680×4320)** - колонки ~1900px, максимальное пространство
2. **4K (3840×2160)** - колонки ~940px, очень широкие колонки
3. **2K (2560×1440)** - колонки ~620px, широкие колонки
4. **Full HD (1920×1080)** - колонки ~460px, комфортная ширина
5. **HD (1440×900)** - колонки ~340px, стандартная ширина
6. **Ноутбук (1366×768)** - колонки ~320px, минимальная комфортная ширина
7. **Планшет (1024×768)** - колонки 320px, горизонтальный скролл
8. **Маленький планшет (900×600)** - колонки 320px, горизонтальный скролл
