## 📋 РУЧНАЯ УСТАНОВКА (если нужно)

### 1. Создать директорию

```bash
ssh root@185.225.34.252
mkdir -p /var/www/app.bike53.ru
```

### 2. Настроить Nginx

```bash
# Скопировать конфигурацию
nano /etc/nginx/sites-available/app.bike53.ru

# Вставить содержимое из nginx-flutter-app.conf

# Активировать
ln -s /etc/nginx/sites-available/app.bike53.ru /etc/nginx/sites-enabled/

# Проверить
nginx -t

# Перезагрузить
systemctl reload nginx
```

### 3. Получить SSL сертификат

```bash
certbot certonly --nginx -d app.bike53.ru
```

### 4. Загрузить приложение

```bash
# На вашем компьютере
flutter build web --release
scp -r build/web/* root@185.225.34.252:/var/www/app.bike53.ru/
```

### 5. Настроить права

```bash
ssh root@185.225.34.252
chown -R www-data:www-data /var/www/app.bike53.ru
chmod -R 755 /var/www/app.bike53.ru
```

## 🌐 CORS настройки

Nginx конфигурация уже включает CORS заголовки для работы с Supabase:

```nginx
add_header Access-Control-Allow-Origin "https://api.bike53.ru" always;
```

Приложение сможет обращаться к вашему Supabase API без проблем!

## 📱 PWA (Progressive Web App)

Flutter Web автоматически создаёт PWA, что позволяет:

- 📲 **Установить на рабочий стол** (как обычное приложение)
- 🔔 **Получать уведомления** (даже когда браузер закрыт)
- 📴 **Работать оффлайн** (если настроить service worker)

Пользователи смогут "установить" приложение через браузер!

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Приложение не открывается

```bash
# Проверить Nginx
nginx -t
systemctl status nginx

# Проверить логи
tail -f /var/log/nginx/app.bike53.ru.error.log
```

### SSL ошибка

```bash
# Обновить сертификат
certbot renew
systemctl reload nginx
```

### Файлы не загружаются

```bash
# Проверить права
ls -la /var/www/app.bike53.ru

# Исправить права
chown -R www-data:www-data /var/www/app.bike53.ru
chmod -R 755 /var/www/app.bike53.ru
```
