ОШИБКА:
  POST https://api.bike53.ru/auth/v1/signup? 500
  (Internal Server Error)

ПРИЧИНА:
  Проблема на стороне сервера Supabase.
  Возможно:
  1. База данных не готова
  2. Supabase Auth не настроен
  3. Проблема с Kong Gateway

═══════════════════════════════════════════════════════════
РЕШЕНИЕ 1: ПРОВЕРИТЬ БАЗУ ДАННЫХ (5 минут)
═══════════════════════════════════════════════════════════

1. Откройте: https://studio.bike53.ru

2. SQL Editor → New query

3. Выполните проверку:

   -- Проверка 1: Таблица user_profiles существует?
   SELECT table_name 
   FROM information_schema.tables 
   WHERE table_schema = 'public' 
     AND table_name = 'user_profiles';
   
   Должно вернуть: user_profiles

4. Если таблицы НЕТ:
   → Примените ПОЛНАЯ_ПЕРЕСБОРКА.sql
   → См. файл НАЧАТЬ_С_НУЛЯ.txt

5. Если таблица ЕСТЬ:
   → Переходите к Решению 2

═══════════════════════════════════════════════════════════
РЕШЕНИЕ 2: ПРОВЕРИТЬ SUPABASE AUTH (3 минуты)
═══════════════════════════════════════════════════════════

1. Supabase Studio → Authentication → Settings

2. Проверьте настройки:
   ✓ Enable email signup: ON
   ✓ Enable email confirmations: OFF
   ✓ Minimum password length: 6

3. Если что-то выключено - включите и сохраните

4. Попробуйте зарегистрироваться снова

═══════════════════════════════════════════════════════════
РЕШЕНИЕ 3: ПРОВЕРИТЬ ЛОГИ SUPABASE (2 минуты)
═══════════════════════════════════════════════════════════

1. Supabase Studio → Logs

2. Выберите: Auth Logs

3. Найдите последнюю ошибку регистрации

4. Прочитайте сообщение об ошибке

5. Сообщите мне текст ошибки для диагностики

═══════════════════════════════════════════════════════════
РЕШЕНИЕ 4: ПРОВЕРИТЬ KONG GATEWAY (SSH)
═══════════════════════════════════════════════════════════

Если у вас есть SSH доступ к серверу:

1. Подключитесь к серверу:
   ssh user@185.225.34.252

2. Проверьте логи Kong:
   docker logs kong-gateway

3. Проверьте логи Supabase Auth:
   docker logs supabase-auth

4. Ищите ошибки в логах

═══════════════════════════════════════════════════════════
РЕШЕНИЕ 5: ВРЕМЕННОЕ - ИСПОЛЬЗОВАТЬ ПРЯМОЙ URL
═══════════════════════════════════════════════════════════

Если Kong не работает, можно временно использовать
прямой URL к Supabase:

1. Откройте: lib/core/constants.dart

2. Измените URL:
   
   БЫЛО:
   static const String supabaseUrl = 'https://api.bike53.ru';
   
   ПОПРОБУЙТЕ:
   static const String supabaseUrl = 'http://185.225.34.252:8000';
   
   ИЛИ (если Kong на другом порту):
   static const String supabaseUrl = 'http://185.225.34.252:54321';

3. Сохраните и перезапустите приложение

4. Попробуйте зарегистрироваться

⚠️  Это временное решение для тестирования!
    Для production используйте домен с SSL.

ДИАГНОСТИКА: ЧТО ПРОВЕРИТЬ
═══════════════════════════════════════════════════════════

1. База данных готова?
   SQL: SELECT * FROM user_profiles LIMIT 1;
   ✓ Запрос выполняется без ошибок

2. Auth включен?
   Authentication → Settings
   ✓ Enable email signup: ON

   SQL: SELECT * FROM pg_trigger WHERE tgname = 'on_auth_user_created';
   ✓ Триггер существует

4. Kong работает?
   curl https://api.bike53.ru/auth/v1/health
   ✓ Возвращает 200 OK

5. Nginx работает?
   curl https://api.bike53.ru
   ✓ Возвращает ответ

САМОЕ ВЕРОЯТНОЕ РЕШЕНИЕ
