# Динамическая ширина карточек задач

## Что изменено

Карточки задач в Kanban теперь автоматически растягиваются на всю ширину колонки без фиксированных брейкпоинтов.

## Проблема

**Было:**
- Карточки имели фиксированную ширину
- Feedback при перетаскивании был фиксированной ширины 280px
- На широких колонках оставалось пустое пространство
- На узких колонках карточки могли выходить за границы

## Решение

Использован `LayoutBuilder` для определения доступной ширины и динамической подстройки.

### Код

**Было:**
```dart
@override
Widget build(BuildContext context) {
  return Draggable<TaskModel>(
    data: task,
    feedback: Material(
      child: Container(
        width: 280, // Фиксированная ширина
        child: _buildCardContent(...),
      ),
    ),
    child: _buildCard(...),
  );
}
```

**Стало:**
```dart
@override
Widget build(BuildContext context) {
  return LayoutBuilder(
    builder: (context, constraints) {
      // Динамическая ширина на основе родителя
      final feedbackWidth = constraints.maxWidth > 0 
          ? constraints.maxWidth - 8 // минус margin
          : 280.0; // fallback ширина
      
      return Draggable<TaskModel>(
        data: task,
        feedback: Material(
          child: Container(
            width: feedbackWidth, // Динамическая ширина
            child: _buildCardContent(...),
          ),
        ),
        child: _buildCard(...),
      );
    },
  );
}
```

## Как это работает

### 1. LayoutBuilder

`LayoutBuilder` предоставляет `constraints` с информацией о доступном пространстве:

```dart
LayoutBuilder(
  builder: (context, constraints) {
    // constraints.maxWidth - максимальная доступная ширина
    // constraints.maxHeight - максимальная доступная высота
    // constraints.minWidth - минимальная ширина
    // constraints.minHeight - минимальная высота
  },
)
```

### 2. Расчет ширины feedback

```dart
final feedbackWidth = constraints.maxWidth > 0 
    ? constraints.maxWidth - 8 // минус margin (4px слева + 4px справа)
    : 280.0; // fallback на случай, если constraints не определены
```

### 3. Применение ширины

```dart
Container(
  width: feedbackWidth, // Используем вычисленную ширину
  padding: const EdgeInsets.all(16),
  child: _buildCardContent(...),
)
```

## Преимущества

### 1. Адаптивность
- ✅ Карточки автоматически подстраиваются под ширину колонки
- ✅ Нет фиксированных размеров
- ✅ Работает на любых экранах

### 2. Оптимальное использование пространства
- ✅ На широких колонках карточки шире
- ✅ На узких колонках карточки уже
- ✅ Нет пустого пространства по бокам

### 3. Консистентность
- ✅ Feedback при перетаскивании той же ширины, что и карточка
- ✅ Визуально понятно, куда перетаскивается задача
- ✅ Нет "прыжков" размера при перетаскивании

### 4. Производительность
- ✅ Расчет происходит только при рендеринге
- ✅ Нет лишних пересчетов
- ✅ Эффективное использование ресурсов

## Поведение при перетаскивании

### 1. Начало перетаскивания
```
Карточка в колонке (ширина = ширина колонки - 8px)
↓
Пользователь начинает перетаскивать
↓
Feedback создается с той же шириной
```

### 2. Во время перетаскивания
```
Feedback следует за курсором
Ширина остается константной (не меняется)
Оригинальная карточка становится полупрозрачной (opacity: 0.4)
```

### 3. Завершение перетаскивания
```
Пользователь отпускает карточку
↓
Карточка перемещается в новую колонку
↓
Карточка принимает ширину новой колонки
```

## Технические детали

### Margin карточки

```dart
Container(
  margin: const EdgeInsets.symmetric(horizontal: 4, vertical: 6),
  // horizontal: 4 = 4px слева + 4px справа = 8px total
  // vertical: 6 = 6px сверху + 6px снизу = 12px total
)
```

### Расчет ширины feedback

```dart
final feedbackWidth = constraints.maxWidth > 0 
    ? constraints.maxWidth - 8 // вычитаем horizontal margin
    : 280.0; // fallback
```

### Fallback ширина

Если `constraints.maxWidth <= 0` (что может произойти в редких случаях):
- Используется fallback ширина 280px
- Гарантирует, что карточка всегда будет видна
- Предотвращает ошибки рендеринга
