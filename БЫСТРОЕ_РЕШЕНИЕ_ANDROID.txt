🔧 БЫСТРОЕ РЕШЕНИЕ ОШИБКИ ANDROID
═══════════════════════════════════════════════════════════

ПРОБЛЕМА:
  Android не может подключиться к api.bike53.ru

РЕШЕНИЕ:
  Используйте локальный Supabase для тестирования

═══════════════════════════════════════════════════════════
ШАГ 1: Запустите локальный Supabase
═══════════════════════════════════════════════════════════

docker-compose -f docker-compose.supabase.yml up -d

═══════════════════════════════════════════════════════════
ШАГ 2: Измените lib/core/constants.dart
═══════════════════════════════════════════════════════════

Откройте файл: lib/core/constants.dart

Замените строки:

БЫЛО:
  static const String supabaseUrl = 'https://api.bike53.ru';
  static const String supabaseAnonKey = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJyb2xlIjoiYW5vbiIsImlzcyI6InN1cGFiYXNlIiwiaWF0IjoxNzc1NDIyODAwLCJleHAiOjE5MzMxODkyMDB9.9Hsb4zE3uIMR3sXjAPVqdx82-ewpdw2eJTDxE1D_z0Q';

СТАЛО:
  static const String supabaseUrl = 'http://192.168.31.153:54321';
  static const String supabaseAnonKey = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJzdXBhYmFzZS1kZW1vIiwicm9sZSI6ImFub24iLCJleHAiOjE5ODM4MTI5OTZ9.CRXP1A7WOeoJeXxjNni43kdQwgnWNReilDMblYTn_I0';

═══════════════════════════════════════════════════════════
ШАГ 3: Пересоберите APK
═══════════════════════════════════════════════════════════

flutter clean
flutter pub get
flutter build apk

═══════════════════════════════════════════════════════════
ШАГ 4: Установите на Android
═══════════════════════════════════════════════════════════

APK находится в:
  build\app\outputs\flutter-apk\app-release.apk

Скопируйте на устройство и установите.

═══════════════════════════════════════════════════════════
✅ ГОТОВО!
═══════════════════════════════════════════════════════════

Теперь приложение будет подключаться к локальному Supabase
на вашем компьютере (IP: 192.168.31.153).

ВАЖНО:
  - Android устройство должно быть в той же Wi-Fi сети
  - Локальный Supabase должен быть запущен
  - Я уже добавил разрешения INTERNET и usesCleartextTraffic

═══════════════════════════════════════════════════════════
АЛЬТЕРНАТИВА: Проверьте доступность api.bike53.ru
═══════════════════════════════════════════════════════════

Если хотите использовать удаленный сервер:

1. Проверьте интернет на Android устройстве
2. Откройте браузер на устройстве
3. Попробуйте открыть: https://api.bike53.ru
4. Если не открывается - проблема в сети/DNS
