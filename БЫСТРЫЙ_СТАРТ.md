# 🚀 Быстрый старт - Настройка Supabase для Task Tracker

## Что вы получите

После выполнения этих шагов у вас будет:
- ✅ Работающий Supabase backend на вашем сервере
- ✅ SSL сертификаты (HTTPS)
- ✅ Nginx reverse proxy
- ✅ Админ панель Supabase Studio
- ✅ Готовое к работе Flutter приложение

## Время установки: ~30 минут

---

## Шаг 1: Подготовка DNS (5 минут)

В панели управления доменами добавьте A-записи:

```
api.bike53.ru       →  185.225.34.252
studio.bike53.ru    →  185.225.34.252
```

Проверьте, что DNS обновился:
```bash
nslookup api.bike53.ru
```

---

## Шаг 2: Подключение к серверу

```bash
ssh root@185.225.34.252
```

---

## Шаг 3: Скопируйте файлы на сервер

Скопируйте все файлы из проекта на сервер в директорию `/opt/supabase`:

```bash
# На вашем компьютере
scp -r nginx-supabase.conf docker-compose.supabase.yml kong.yml .env.example setup-supabase.sh generate-jwt.sh monitor-supabase.sh root@185.225.34.252:/opt/supabase/
```

Или клонируйте репозиторий:
```bash
# На сервере
mkdir -p /opt/supabase
cd /opt/supabase
# Скопируйте файлы вручную
```

---

## Шаг 4: Автоматическая установка (15 минут)

```bash
cd /opt/supabase

# Сделайте скрипты исполняемыми
chmod +x setup-supabase.sh generate-jwt.sh monitor-supabase.sh

# Запустите автоматическую установку
sudo bash setup-supabase.sh
```

Скрипт установит:
- Docker и Docker Compose
- Nginx
- Certbot
- SSL сертификаты
- Конфигурацию Nginx

---

## Шаг 5: Генерация секретов (2 минуты)

```bash
bash generate-jwt.sh
```

Скрипт создаст файл `jwt-keys.txt` с:
- JWT Secret
- Anon Key
- Service Role Key

**ВАЖНО:** Сохраните эти ключи в безопасном месте!

---

## Шаг 6: Настройка переменных окружения (3 минуты)

```bash
# Создайте .env файл
cp .env.example .env

# Отредактируйте .env
nano .env
```

Обновите следующие значения из `jwt-keys.txt`:
- `POSTGRES_PASSWORD` - сгенерированный пароль
- `JWT_SECRET` - сгенерированный JWT secret
- `SUPABASE_ANON_KEY` - сгенерированный anon key
- `SUPABASE_SERVICE_KEY` - сгенерированный service key

Сохраните: `Ctrl+X`, затем `Y`, затем `Enter`

---

## Шаг 7: Обновление Docker Compose (2 минуты)

```bash
nano docker-compose.supabase.yml
```

Замените все вхождения:
- `your-super-secret-and-long-postgres-password` → ваш POSTGRES_PASSWORD
- `your-super-secret-jwt-token-with-at-least-32-characters-long` → ваш JWT_SECRET

Сохраните: `Ctrl+X`, затем `Y`, затем `Enter`

---

## Шаг 8: Запуск Supabase (3 минуты)

```bash
# Создайте директории для данных
mkdir -p volumes/db/data volumes/storage volumes/kong

# Скопируйте конфигурацию Kong
cp kong.yml volumes/kong/

# Запустите все сервисы
docker-compose -f docker-compose.supabase.yml up -d

# Проверьте статус (все должны быть "Up")
docker-compose -f docker-compose.supabase.yml ps
```

---

## Шаг 9: Проверка работы (2 минуты)

```bash
# Проверьте API
curl https://api.bike53.ru/health

# Должен вернуть: healthy
```

Откройте в браузере:
- **Studio**: https://studio.bike53.ru

---

## Шаг 10: Настройка Flutter приложения (3 минуты)

1. Откройте Studio: https://studio.bike53.ru
2. Перейдите в **Settings** → **API**
3. Скопируйте **anon** ключ

4. Откройте файл `lib/core/constants.dart` в вашем проекте:

```dart
class AppConstants {
  static const String appName = 'Планировщик задач';

  // Обновите эти значения
  static const String supabaseUrl = 'https://api.bike53.ru';
  static const String supabaseAnonKey = 'ВАШ_ANON_KEY_ИЗ_STUDIO';

  // ... остальной код
}
```

5. Пересоберите приложение:
```bash
flutter clean
flutter pub get
flutter run
```

---

## Шаг 11: Настройка базы данных (5 минут)

```bash
# Выполните миграцию схемы
docker exec -i supabase-db psql -U postgres postgres < database_schema.sql

# Если есть миграция данных
docker exec -i supabase-db psql -U postgres postgres < database_migration.sql
```

Проверьте в Studio, что таблицы созданы.

## 🔧 Полезные команды

```bash
# Просмотр логов
docker-compose -f docker-compose.supabase.yml logs -f

# Статус Nginx
sudo systemctl status nginx

# Перезапуск Nginx
sudo systemctl restart nginx
```

## 🆘 Проблемы?

### 502 Bad Gateway

```bash
# Проверьте, запущены ли контейнеры
docker-compose -f docker-compose.supabase.yml ps

# Перезапустите
docker-compose -f docker-compose.supabase.yml restart
```

### SSL ошибки

```bash
# Проверьте сертификаты
sudo certbot certificates

# Обновите
sudo certbot renew
```

### База данных не запускается

```bash
# Проверьте логи
docker-compose -f docker-compose.supabase.yml logs db

# Очистите и перезапустите (ВНИМАНИЕ: удалит данные!)
docker-compose -f docker-compose.supabase.yml down -v
rm -rf volumes/db/data/*
docker-compose -f docker-compose.supabase.yml up -d
```
