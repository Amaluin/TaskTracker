ПРОБЛЕМА:
  Ошибка 401 (Unauthorized) при регистрации
  
ПРИЧИНА:
  В файле lib/core/constants.dart стоит:
  supabaseAnonKey = 'YOUR_SUPABASE_ANON_KEY'
  
  Это шаблон, а не настоящий ключ!

═══════════════════════════════════════════════════════════
РЕШЕНИЕ: ПОЛУЧИТЬ НАСТОЯЩИЙ ANON KEY (2 минуты)
═══════════════════════════════════════════════════════════

1. Откройте: https://studio.bike53.ru

2. В левом меню выберите: Settings (⚙️)

3. Выберите вкладку: API

4. Найдите раздел: "Project API keys"

5. Скопируйте ключ: "anon public"
   (Это длинная строка, начинается с "eyJ...")

6. Откройте файл: lib/core/constants.dart

7. Замените строку:
   
   БЫЛО:
   static const String supabaseAnonKey = 'YOUR_SUPABASE_ANON_KEY';
   
   СТАЛО:
   static const String supabaseAnonKey = 'eyJ...ваш_ключ...';

8. Сохраните файл (Ctrl+S)

9. Перезапустите приложение:
   - Остановите: Ctrl+C
   - Запустите: flutter run

10. Попробуйте зарегистрироваться снова
