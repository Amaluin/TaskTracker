# Иконки приложения

## Требуемые файлы:

1. **app_icon.png** - Основная иконка (1024x1024 px)
   - Полная иконка с фоном
   - Используется для генерации всех размеров

2. **app_icon_foreground.png** - Foreground для Android Adaptive Icon (1024x1024 px)
   - Только часы с галочкой (белые)
   - Прозрачный фон
   - Используется для адаптивных иконок Android

## Как добавить:

1. Сохраните изображение иконки (часы с галочкой на бирюзовом фоне) как `app_icon.png`
2. Создайте версию без фона как `app_icon_foreground.png`
3. Запустите: `dart run flutter_launcher_icons`

## Цвет фона

Adaptive icon использует цвет фона: `#5F9EA0` (Cadet Blue)
