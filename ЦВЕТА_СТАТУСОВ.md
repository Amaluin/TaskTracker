## Где применяются цвета

1. **Фон карточки задачи** - градиент от фонового цвета статуса
2. **Граница карточки** - основной цвет статуса с прозрачностью
3. **Иконка статуса** - основной цвет статуса
4. **Бейдж статуса** - фоновый цвет с текстом основного цвета
5. **Колонки Kanban** - градиентный фон и цветная граница
6. **Тень карточки** - основной цвет статуса с прозрачностью

## Визуальные эффекты

- **Градиенты**: Используются для создания глубины и современного вида
- **Прозрачность**: Применяется для создания мягких переходов
- **Тени**: Цветные тени соответствуют статусу задачи
- **Анимации**: Плавные переходы при изменении статуса (200ms)
- **Hover эффекты**: Усиление цвета при наведении в Kanban режиме

## Файлы с реализацией

- `lib/core/constants.dart` - функции `getStatusColor()` и `getStatusBackgroundColor()`
- `lib/widgets/task_card.dart` - карточка задачи в списке
- `lib/widgets/draggable_task_card.dart` - перетаскиваемая карточка в Kanban
- `lib/widgets/kanban_column.dart` - колонка Kanban доски
