# Отладка напоминаний

## Что добавлено

### 1. Логирование
Добавлены print-сообщения для отслеживания процесса создания напоминания:
- 📅 "Создаём напоминание на: [дата]"
- 💾 "Сохраняем напоминание в БД: [id]"
- 🔔 "Планируем уведомление"
- ✅ "Напоминание создано успешно"
- ❌ "Ошибка создания напоминания: [ошибка]"

### 2. Уведомления пользователю
- ✅ Зелёное уведомление при успешном создании напоминания
- ⚠️ Оранжевое уведомление при ошибке создания напоминания

### 3. Обработка ошибок
Добавлен try-catch блок для отлова ошибок при создании напоминания

## Как проверить

### Шаг 1: Откройте логи
В Android Studio или VS Code откройте вкладку "Debug Console" или "Run"

### Шаг 2: Создайте задачу с временем
1. Откройте приложение
2. Нажмите "Новая задача"
3. Заполните название
4. Выберите дату и время (например, через 5 минут)
5. Нажмите "Сохранить задачу"

### Шаг 3: Проверьте логи
Вы должны увидеть в консоли:
```
📅 Создаём напоминание на: 2026-04-12 15:30:00.000
💾 Сохраняем напоминание в БД: abc-123-def
🔔 Планируем уведомление
✅ Напоминание создано успешно
```

### Шаг 4: Проверьте уведомление
Должно появиться зелёное уведомление:
"Напоминание установлено на 12.4.2026 15:30"

### Шаг 5: Проверьте в детальном экране
1. Откройте созданную задачу
2. Прокрутите до раздела "Напоминания"
3. Должно отображаться созданное напоминание

## Возможные проблемы

### Проблема 1: Не видно логов
**Решение:** Убедитесь, что приложение запущено в режиме отладки (Debug mode)

### Проблема 2: Ошибка "Пользователь не авторизован"
**Решение:** Выйдите и войдите заново в приложение

### Проблема 3: Ошибка сохранения в БД
**Решение:** Проверьте подключение к интернету и настройки Supabase

### Проблема 4: Ошибка планирования уведомления
**Решение:** 
- Проверьте, что разрешения на уведомления предоставлены
- Проверьте, что разрешение на точные будильники предоставлено
- Перезапустите приложение

### Проблема 5: Напоминание не отображается в списке
**Решение:**
- Закройте и откройте задачу заново
- Проверьте, что напоминание сохранилось в БД (смотрите логи)
- Перезапустите приложение

## Проверка в Supabase

1. Откройте Supabase Dashboard
2. Перейдите в Table Editor
3. Откройте таблицу `task_reminders`
4. Проверьте, что напоминание добавлено:
   - `task_id` - ID задачи
   - `user_id` - ID пользователя
   - `remind_at` - время напоминания
   - `enabled` - должно быть `true`

## Проверка системных уведомлений

### Android
1. Откройте Настройки → Приложения → Task Tracker
2. Проверьте разрешения:
   - ✅ Уведомления
   - ✅ Будильники и напоминания
3. Если разрешения не предоставлены, включите их

## Если ничего не помогает

1. Удалите приложение
2. Пересоберите проект: `flutter clean && flutter build apk`
3. Установите заново
4. Проверьте логи при создании задачи
5. Отправьте логи для анализа
